# AI Workshop: Local & Cloud LLM Integrations

Welcome to the AI Workshop repository! This project covers hands-on implementations exploring speech recognition, web tunneling, cloud API inference, and local LLM deployment.

## Workshop Topics Covered
1. **Text-to-Speech (TTS) & Speech-to-Text (STT)**
2. **Web Tunneling with ngrok**
3. **Cloud LLM Acceleration with Groq**
4. **Local LLM Execution with Ollama**
